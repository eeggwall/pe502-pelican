PE502 is the research site of Charles Reid. It started with Project Euler problem 502 and kept going, because the counting problem turned out to touch generating functions, number fields, spectra, signals, and codes.

A **castle** of width *w* and height *h* is a row of *w* columns standing on a common base, with column heights *c*<sub>1</sub>, ..., *c*<sub>*w*</sub> between 1 and *h* and at least one column reaching *h*. A **block** is a maximal horizontal run of filled cells in a single row, so the full bottom row is one block. The problem asks how many castles have an even number of blocks, on grids as large as 10<sup>12</sup> in one dimension. [PE502-1](/publications/PE502-1/) is a self-contained introduction.

## What gets posted

Posts
:   Short, dated updates: a new count, a conjecture checked to some size, a note on work in progress, or the announcement of a new publication or web app. Posts have no numbers and are not part of the publication series.

Publications
:   Standalone documents with a permanent number: PE502-1, PE502-2, and so on. The number says nothing about topic or type. A publication is frozen when it is issued; a correction or revision gets a new number that names the publication it replaces, and both stay available.

Divisions
:   Subject headings for sorting posts and publications. A post or a publication can be tagged with several divisions. Divisions never appear in a publication number.

## Publication types

| Type | Use |
| --- | --- |
| Technical Report | Completed work, with results others can use |
| Working Note | A preliminary or failed approach, written up so it stays findable |
| Computational Record | Code, data and environment details, pinned to a repository tag or commit |
| Seminar Notes | Notes from a seminar |
| Problem Set | Problems, with or without solutions |
| Errata | Corrections to an earlier publication |
